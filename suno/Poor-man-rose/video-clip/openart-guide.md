## Before you open OpenArt

1. Aspect: **16:9**, prefer **2k / High**. Add 9:16 later only if needed.
2. Leave **Auto Polish OFF** — it rewrites prompts and can undo lighting geometry.
3. Generate **4 variations** when the plate is important (not 1).
4. Hard rules for every generation:
   - **No people** in any frame
   - **Winter = generate in colour** (grade B&W later — never prompt monochrome)
   - Shot 5 is the only winter clip that stays colour
   - **Snow stays on high peaks** in every summer plate
   - Full **double rainbow only in chorus 2 + outro** (faint partial arcs earlier)
   - Sun for rainbow plates: **off frame, behind camera, slightly to one side**

## Approval checks (use these every time)

### Global — reject immediately if any of these appear

- [ ] People, hands, faces, silhouettes of humans
- [ ] Text, logos, watermarks
- [ ] Cartoon / illustration / 3D-render look
- [ ] Wrong flowers (roses, fireweed when the plate should be lupine, or the reverse)
- [ ] Wrong aspect (not 16:9)

### Swan lock — `swan-lock.png`

**Pass when:**
- [ ] Two swans **facing each other**
- [ ] Necks curve into heart / intimate negative space
- [ ] Both birds fully visible, clean silhouettes
- [ ] Feels like lovers, not a wildlife ID photo

**Reject when:**
- [ ] Both birds face the same direction
- [ ] Standing on land / stones as the main pose
- [ ] Deformed necks, extra wings, mashed anatomy
- [ ] Clinical zoo / field-guide lighting

### Plate L — `plate-lupiinit.png` (arrival)

**Pass when:**
- [ ] Layers bottom → top: flower carpet → lake → snow mountains → big sky
- [ ] Lupine carpet fills **lower third only** (sky stays large enough to fly in)
- [ ] **Snow on peaks** (heavy, readable)
- [ ] **Double rainbow** with dark squall / rain haze behind it
- [ ] Sun **not** visible in frame (warm light from behind camera)
- [ ] Lit ground against dark sky (high contrast)
- [ ] Empty — no birds, no people

**Reject when:**
- [ ] Sticker rainbow on clear / pink sunset sky
- [ ] Single pale rainbow only
- [ ] Sun visible in the same frame as the rainbow
- [ ] Flowers climb past the lower third (nowhere to fly)
- [ ] Bare brown snowless peaks
- [ ] Merely pretty postcard with no weather

**Directing note after approve:** rainbow arch is a gate — keep swans **off centre** later; do not park the pair in the middle of the arc.

### Plate L-AIR — `plate-lupiinit-air.png`

**Pass when:**
- [ ] Clearly the **same valley** as `plate-lupiinit.png`
- [ ] High aerial looking down and forward
- [ ] Same snow peaks + same double rainbow weather language
- [ ] Rainbow still sits **ahead** in the sky (not viewed from above looking down through the arc)
- [ ] Empty — no birds, no people

**Reject when:**
- [ ] Different mountains / different lake (new place invented)
- [ ] Camera looking down *through* the rainbow from above
- [ ] Clear sky / sticker rainbow
- [ ] Too low — reads as another ground plate

### Plate W — `plate-winter.png`

**Pass when:**
- [ ] Generated in **colour** (cool blues/greys OK — not monochrome)
- [ ] Dead fireweed stalks graphic and readable against snow
- [ ] Black open water lead visible (ink scar in white)
- [ ] Strong tonal contrast (will survive B&W grade)
- [ ] Empty — no birds, no people

**Reject when:**
- [ ] Prompted or returned as black-and-white
- [ ] Soft muddy grey with no graphic stalks
- [ ] No open water
- [ ] Tidy garden / pretty snowfield with no charred ground

### Plate T — `plate-thaw.png` / `plate-thaw-late.png`

**Pass when:**
- [ ] **Green and only green** — new grass, shoots, moss
- [ ] **Zero flowers, zero buds, no magenta/pink/violet anywhere**
- [ ] Last year's dead black stalks still standing in the new growth
- [ ] Same coastline, headland and range as `plate-winter.png`
- [ ] Meltwater visible — rivulets or pools
- [ ] Muted and cool, not lush summer
- [ ] Empty — no birds, no people

**Reject when:**
- [ ] Any bloom at all, even a single bud → the chorus loses its payoff
- [ ] Full lush summer green (that's the wrong season)
- [ ] Dead stalks removed — the old year has to still be there
- [ ] New location instead of the winter coast
- [ ] Warm golden light

### Plate F — `plate-maitohorsma.png`

**Pass when:**
- [ ] Magenta **maitohorsma / fireweed** (tall narrow spikes — not lupine)
- [ ] Coast or slopes + water / mountains readable
- [ ] Cooler / more muted than Plate L (chorus 1 energy)
- [ ] Snow on distant peaks if mountains are in frame
- [ ] Empty — no birds, no people

**Reject when:**
- [ ] Lupine instead of fireweed
- [ ] Full double rainbow (withheld for Plate L / chorus 2)
- [ ] Warm saturated postcard matching Plate L

### Plate P — `plate-peaks.png` (optional)

**Pass when:**
- [ ] Jagged peaks are the subject; flowers are scale
- [ ] Heavy snow on summits / couloirs
- [ ] Harder / colder than Plate L
- [ ] Empty — no birds, no people, no rainbow

**Reject when:**
- [ ] Soft tourist peaks
- [ ] Rainbow present (this is the climb, not the arrival)

### Video tests (Phase 2)

**Test A — reunion (shot 24)**
- [ ] Pass: greeting energy — facing, necks arched, wings half-raised
- [ ] Reject: mashed anatomy, three heads, ducks, people

**Test B — lupine reveal (shot 28)**
- [ ] Pass: pair **small** in frame, scale and beauty first, off-centre under/through arc
- [ ] Reject: broken close-up wings, pair centred in the rainbow logo, wrong flowers

### Flight clips (any airborne shot)

**Low flight is the default — wingtip height, just above the flowers or the water.** Height is
allowed in exactly two shots: 28 (ridge crest reveal) and 33 (widest frame of the outro).

**Pass when:**
- [ ] Foreground rips past — you can feel speed
- [ ] The bird has scale against flower spikes or water
- [ ] Side-tracking with the birds, not pointing at them
- [ ] Wake visible: seed-down, petals, spray, shadow racing the ground

**Reject when:**
- [ ] High glide where nothing moves and flight reads as a hover
- [ ] Lupine flattened into a featureless purple stain (too high)
- [ ] Static close-up of a working wing (anatomy soup)
- [ ] Giant birds filling the frame
- [ ] Pair parked dead centre in the rainbow arch
